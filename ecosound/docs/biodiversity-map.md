# Community biodiversity map

An observation may be shared only after a user explicitly accepts the current consent version. GPS is optional and is requested only after the user chooses to include it and submits the observation. The audio recording remains private. Public records use separate generalized coordinates; the API never returns the precise stored latitude/longitude. The default coarse precision rounds to two decimal places; `OBSERVATION_LOCATION_PRECISION=very_coarse` rounds to one decimal place. Species absent from the curated knowledge table are treated as sensitive by default and omitted from the public map. Curated records can also be marked sensitive.

The map reads only `/api/map/observations` and supports species, date, status, and destination filters. It renders approximate point markers and labels personal confirmations separately from expert verification. No map rows are seeded. There is a real empty state when no public coordinate-bearing observations exist. Private and no-location contributions are excluded from that endpoint. Expert-verified status is not client writable.

MapLibre GL JS (MIT) is lazily loaded for the map screen from its published CDN bundle. Tiles use OpenFreeMap's hosted style with OpenStreetMap data attribution. MapLibre code and map tiles are separate services and their own terms apply; map tiles need connectivity and are not cached offline. The user's consent and approximate location may be transmitted to the local EcoSound instance; public generalized coordinates may be visible to other map users. In this MVP, there is no account ownership or authenticated moderation, so keep the API on localhost or a trusted network.
