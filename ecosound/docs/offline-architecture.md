# Offline-first behavior

EcoSound is a PWA with a manifest, shell service worker, and IndexedDB stores. The service worker caches the app shell and same-origin static Next assets. The frontend also best-effort caches successful GET JSON by URL in IndexedDB, including loaded quest instructions, generated adventure records, destinations, and curated species information. Cached data is for the single local browser profile; clearing browser site data removes it. The user can start an adventure while connected and revisit its stored task list offline.

Browser recordings remain in IndexedDB until successfully sent to the Go backend. Reconnection uploads them using a stable UUID `Idempotency-Key`; the backend hashes content and refuses a changed payload under the same key. The result is stored for user review. BirdNET still runs on the server and therefore needs a connection. A no-network recording does not produce a local prediction. Discovery saves, adventure task completion, finish/reflection, and consented observation creation use a local queue with unique operation IDs, creation order, retry state, and `/api/sync`. The server stores operation payload hashes/results and rejects an ID reused for different data. Discovery, task, observation, and XP uniqueness constraints provide additional deduplication.

When connectivity returns, EcoSound attempts synchronization on the online event and offers a manual sync action on an active adventure/recording screen. Some browsers suspend pages in the background; synchronization is not guaranteed until the app is opened. Map tiles, BirdNET, Qwen generation/explanations, NatureLM inference, and new server data require a network connection. This is offline caching and queued capture, not on-device inference.

No authentication exists, so this queue represents one local user talking to one local API. The backend does not infer identity or grant access to another person's profile. Browser quota can prevent storage; the UI reports a storage failure and the user should preserve the original file. IndexedDB recordings include private wildlife audio; clearing site data removes local pending copies.
