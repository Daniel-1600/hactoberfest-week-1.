# NatureLM-audio integration

NatureLM is an optional provider for experimental audio descriptions. BirdNET remains the bird classifier. NatureLM output is represented as timed or untimed text descriptions with `species_identification: false`; EcoSound does not turn these descriptions into species labels or quest credit.

The adapter was checked against the Earth Species Project repository API (`NatureLM.from_pretrained`, `Pipeline(model=...)`, then `pipeline(audio_paths, queries, window_length_seconds, hop_length_seconds)`). The Python HTTP sidecar loads once at startup on loopback port 8091 and accepts normalized mono PCM WAV only. It supports `audio_description` and `vocalization_characteristics`, validates the documented list-of-text result, and keeps temporary files short-lived. Go applies the configured call timeout and reports availability via `/api/inference/providers`.

The official example uses CUDA and the NatureLM checkpoint is based on Meta Llama 3.1 8B. The repository requires users to obtain/accept the upstream Llama license and access to the weights. Hardware requirements depend on precision, runtime, and available memory; EcoSound has not benchmarked them. This environment has not installed the gated weights, CUDA stack, or official repo, so real NatureLM inference is not verified. `NATURELM_ENABLED=false` is the default.

To prepare a separate Python environment, follow the exact installation and model access instructions in the [official NatureLM-audio repository](https://github.com/earthspecies/NatureLM-audio). Point `NATURELM_REPO_PATH` at that checkout, set `NATURELM_MODEL_PATH` to the authorized model identifier or local path, and run `python inference/naturelm_server.py` from its compatible environment. Set `NATURELM_ENABLED=true` and the API endpoint only after `/health` returns ready. Never commit either the repository's model files or the gated base model. Consult the repository and model-card terms; they are separate from EcoSound's MIT license.
