# AI outdoor adventures

`POST /api/adventures/generate` accepts a duration (10, 15, 30, or 60 minutes), interest, environment, difficulty, and optional accessibility preference. It asks a persistent OpenAI-compatible local Qwen 3-1.7B server for JSON, validates every task and safety rule, retries once, then stores a clearly labeled safe fallback if generation is unavailable or invalid. The generated content cannot create trails, access rights, verified wildlife, or accessibility facts. Destination experiences remain curated server records.

The Explore screen shows “Generated by Qwen” or “Safe fallback adventure.” Start an adventure while online; its stored tasks are cached for later. When `environment` is `approved_nature_destination`, the request must include a destination ID whose server record is verified; the Karura concept is not eligible. Only approved experience guidance stored on that verified destination is supplied to Qwen. AI-linked tasks credit only a saved BirdNET discovery, with a database uniqueness rule preventing one saved discovery from earning task XP twice. Observation and reflection tasks are self-reported. Adventure completion and reward events are persistent and idempotent.

## Local Qwen service

Install and run a local Ollama release, then download the open-weight model once and leave Ollama running as the persistent process:

```sh
ollama pull qwen3:1.7b
ollama serve
```

Set `QWEN_ENABLED=true`, `QWEN_MODEL_PATH=qwen3:1.7b`, and the OpenAI-compatible `QWEN_ENDPOINT` in `.env`. The server checks `/v1/models`; `/api/inference/providers` reports current availability. llama.cpp servers that implement the OpenAI chat-completions and models endpoints can be used by changing those values. Quantized GGUF use depends on the local server's model configuration. EcoSound does not load weights for each request and sends no prompt to a hosted paid inference service.

Qwen3-1.7B weights are separately licensed under Apache-2.0; this is not the application or BirdNET model license. Runtime speed and memory depend on quantization, context, and CPU/GPU and were not benchmarked in this environment. Real Qwen generation has not been verified here because no local model server or weights are installed. The safe fallback is functional but is not model output.

The AI endpoint receives user preferences, not GPS. Keep free-text accessibility needs short and avoid entering sensitive personal information. Do not use a generated adventure as permission to enter a property or restricted habitat.
