# Privacy, consent, and scientific integrity

EcoSound stores recordings and normalized audio on the server's local filesystem and stores metadata in SQLite. It has no accounts/authentication and is intended for localhost use. Anyone who can reach the API can access this single user's discoveries and audio. Bind to `127.0.0.1` unless the operator explicitly trusts the network. Recordings are not automatically published, placed in an open dataset, or used to retrain BirdNET.

Microphone access happens only after the user starts recording. Location access is never required for discovery and is requested only after the user chooses to contribute an observation and checks the optional-location box. The consent checkbox is mandatory to share. A private exact coordinate is stored only when supplied for an observation; the public map API reads only the generalized columns and omits private, rejected, and sensitive/unmapped species. Audio has separate privacy and remains private. `OBSERVATION_LOCATION_PRECISION` defaults to coarse (two decimal places), with very-coarse one decimal place.

BirdNET candidates and scores can be wrong and are not guaranteed calibrated probabilities. Personal confirmation records a user's judgment only. Observation status `expert_verified` can be set only through an authorized review process that this MVP does not provide. No user action can create that status. An AI-generated NatureLM description is not a species identification. Self-reported outdoor minutes and tasks are not measured or independently verified.

The local browser caches fetched data and can retain unuploaded recordings and queued operations in IndexedDB. On a shared device, other users of the same browser profile may see this cache. Browser storage is not encrypted by EcoSound. The map screen loads MapLibre from a CDN and requests OpenFreeMap/OSM-backed tiles; those providers receive normal network metadata such as IP address. Map tiles are not downloaded for offline use.
